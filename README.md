# ♻️ EcoSort AI – Intelligent Waste Segregation System

EcoSort AI is a smart waste management prototype designed to promote responsible waste disposal and environmental sustainability. The project demonstrates how technology can help users identify waste materials, understand waste categories, and learn appropriate disposal practices.

The system is built using Python and Streamlit, providing a simple and interactive web interface for demonstrating the waste segregation process.

## 🌟 Features

- **Interactive Web Interface:** Simple and user-friendly interface developed using Streamlit.
- **Waste Identification Demo:** Demonstrates the identification of a sample waste item.
- **Waste Classification:** Illustrates how waste can be categorized based on material type.
- **Disposal Guidance:** Provides information to help users understand appropriate waste disposal practices.
- **Environmental Awareness:** Encourages recycling, waste reduction, and responsible waste management.
- **Expandable Architecture:** Can be extended with machine learning models and real-time waste image classification.

## 🎯 Project Objectives

- Promote effective waste segregation and recycling.
- Demonstrate the application of AI concepts in waste management.

## ⚙️ Installation and Setup

### Prerequisites

- Python 3.9 or later
- pip package manager
- Git (optional)

### Step 1: Clone the Repository

```bash
git clone <YOUR_REPOSITORY_URL>
cd EcoSort-AI
```

Replace `<YOUR_REPOSITORY_URL>` with your actual GitHub repository URL.

### Step 2: Create a Virtual Environment (Optional)

```bash
python -m venv venv
```

Activate the environment on Windows:

```bash
venv\Scripts\activate
```

### Step 3: Install Dependencies

```bash
pip install -r requirements.txt
```

### Step 4: Run the Application

```bash
streamlit run app.py
```

The application will open in your default web browser. If it does not open automatically, use the local URL displayed in the terminal.

## 🚀 How It Works

1. Launch the EcoSort AI application.
2. Open the interactive waste segregation interface.
3. View the demonstration using a sample waste item.
4. Explore the displayed waste classification and disposal information.
5. Use the prototype to understand how intelligent waste segregation systems can support recycling and sustainability.

**Note:** The current version demonstrates the workflow using a predefined sample result. Automated image recognition and dynamic location-based disposal recommendations are potential future enhancements.
